# T21_B Interview Preparation Pack

This folder is a focused learning pack for the System Development Engineer role described in [job_offer.txt](./job_offer.txt).

## What matters for this role

- Systems engineering across the full V-cycle
- Requirements elicitation, analysis, definition, and change management
- Power electronics basics, especially motor drive inverters
- Cross-functional work across software, hardware, test, and suppliers
- Automotive process knowledge: FMEA, FTA, ASPICE, ISO 26262
- Clear technical communication in English

## How to use this pack

Read one file at a time. After each file, answer the practice task without looking back at the notes. If you cannot explain a topic in simple English, you do not own it yet.

## Good interview answer pattern

For most system-engineering questions, use this structure:

1. Start from system goal and customer need.
2. Describe constraints and risks.
3. Explain how you derive requirements or architecture.
4. Show how you verify the result.
5. Mention tradeoffs and change handling.

## Senior-level insight

For this role, the interviewer is usually not checking whether you memorized definitions. They are checking whether you can connect requirements, architecture, test coverage, risk analysis, and change control into one coherent engineering story.
